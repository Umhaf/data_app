# 📱 DATA App - Telecom & Airtime Platform

**Hausa/English Documentation**

## 🎯 Overview
DATA App adalah aplikasi mobile untuk membeli airtime, data, membayar tagihan TV, dan layanan telecom lainnya.

**Data App ne app na mobile don siyan airtime, data, biyan kudin gida (bills), da sauran ayyukan jiya da jiya.**

---

## ✨ Features

### Basic Features ✅
- User registration & login
- Wallet balance management
- Buy airtime
- Buy data plans
- Transaction history
- User profile page

### Advanced Features ✅
- Fund wallet
- Bill payments
- TV subscription
- Referral bonus system
- Admin panel

## 🚀 Getting Started

### Prerequisites
- Flutter SDK installed
- Android Studio / VS Code
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/UmhafTo/data_app.git
cd data_app

# Get dependencies
flutter pub get

# Run the app
flutter run
```

### Using GitHub Codespaces (From Phone)
1. Go to: https://github.com/UmhafTo/data_app
2. Click "Code" → "Codespaces" → "Create codespace"
3. In terminal: `flutter pub get && flutter run -d chrome`
